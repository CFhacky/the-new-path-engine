SOURCE PACKET: World of Warcraft weapon enchants, Classic through Warlords of Draenor (profession enchants, shaman imbues, death knight runeforging).
GATHERED: 2026-10-04 by web search (3+ queries) and full-page fetches of warcraft.wiki.gg pages; one page per enchant plus the WeaponEnchantID roster page (62 IDs) and the Enchantments-by-slot page (truncated after the Hands section).
FIDELITY: WebFetch returns a small model's extraction of each page, not a byte-exact copy. Tooltips below are quoted as returned; every number is as returned; anything the page did not give is marked NOT PRESENT and is never filled from memory. "Secondary" marks a figure taken from a search-result snippet of another page (stated per entry). The WoD marks came from the truncated slot page only (their own pages returned 404): flagged degraded.
SCOPE: effect and proc enchants. Plain flat-stat enchants (Agility, Strength, Spellpower, Striking and the like), cosmetic and test IDs are excluded. Crusader is already ratified (Registry section 2) and is not repeated.
Format: "=== NAME ===", then key: value lines. Blocks end at the next "===".
