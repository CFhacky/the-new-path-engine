# reference/addresses/ — pinned address maps (the Stephanus layer)

One map per book, generated by `scripts/verse_address.py`. A map gives every
unit of a book a stable address (`TEATD1 4:xviii`, `TEATD1 4:xviii ¶3`), an
anchor id that the EPUB from `scripts/notion_novel_bind.py` carries on the
same heading and paragraph, a line span, a paragraph count, an optional verse
title and an incipit. **No body text.** The books themselves live in the
sourcebook corpus and are never committed.

Each map pins its edition by SHA-256. An address is valid only against that
file; `--verify` refuses a mismatched file, and a fresh export from Notion
with different paragraphing is a new edition with a new map.

These are corpus metadata, not mechanical reference entries: they are not
registered in `families.json` and the reference audit does not count them.
They are the address layer that `reference/canon/events.json` and
`scripts/canon_table.py` cite.

| Map | Book | Scheme | Units |
|---|---|---|---|
| `teatd1.address.json` | The End and the Death Volume I | verse | chapters 1–4 |
| `teatd2.address.json` | The End and the Death Volume II | verse | chapters 5–8 |
| `teatd3.address.json` | The End and the Death Volume III | verse | chapters 9–10 + Fragments (`F:i`–`F:v`) |

To add a book from the Heresy library:

```
python scripts/verse_address.py "<corpus>/<book>.md" --key SOT-SAT --title "Saturnine" --out reference/addresses/sot-sat.address.json
```

then point its row in `reference/canon/events.json` at the map.
